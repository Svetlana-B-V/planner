# 🌟 AuraTask: Многоуровневый Органайзер

![AuraTask Preview](https://img.shields.io/badge/Status-Active-success) ![Vanilla JS](https://img.shields.io/badge/JavaScript-Vanilla-f7df1e?logo=javascript) ![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?logo=tailwind-css)

**AuraTask** — это современный, красивый и функциональный веб-органайзер, созданный для удобного управления рабочими проектами, хакатонами, коммунальными платежами и повседневными делами. 

Интерфейс использует дизайн **Glassmorphism**, реагирует на смену времен года и включает в себя интерактивного виртуального питомца — Кота-Ниндзю 🐈‍⬛, который следит за вашими дедлайнами!

---

## ✨ Ключевые возможности

*   **📂 Многоуровневая структура:** Создавайте проекты, в них — задачи, а в задачах — неограниченное количество подзадач.
*   **📊 Диаграмма Ганта:** Визуализируйте активные задачи на временной шкале. Задавайте кастомные цвета для каждой задачи!
*   **📅 Интерактивный Календарь:** Быстрый просмотр задач на выбранный день. Мультидневные задачи отображаются линиями под датами.
*   **🐈 Кот-Ассистент:** Виртуальный питомец, который гуляет по экрану (плавные 60 FPS) и напоминает об истекающих дедлайнах (за 2 дня до конца).
*   **🌦 Сезонные темы:** Оформление (фон и частицы) автоматически меняется в зависимости от времени года (цветущая весна, летние лепестки, осенние листья, зимний снег). Можно переключить вручную.
*   **📈 Детальная статистика:** Отслеживание прогресса выполнения проекта в красивых круговых диаграммах.
*   **💾 Локальное сохранение:** Все ваши данные надежно хранятся прямо в вашем браузере (`localStorage`). Никаких серверов и регистраций.

## 🛠 Технологии

Проект не требует сложных систем сборки (Node.js, Webpack). Он готов к работе прямо "из коробки".

*   **HTML5**
*   **Tailwind CSS** (через CDN)
*   **Vanilla JavaScript** (ES6)
*   **FontAwesome** (Иконки)

## 🚀 Как запустить

1. Склонируйте репозиторий или скачайте архив с проектом.
2. Убедитесь, что структура папок выглядит следующим образом:
   
```text
   📦 auratask-project
    ┣ 📂 cat-assistant
    ┃ ┣ 📂 img          # Спрайты кота (walk_cycle_*.png, sit_pose.png)
    ┃ ┣ 📜 cat-styles.css
    ┃ ┗ 📜 cat-assistant.js
    ┣ 📜 main.html    # Главный HTML файл
    ┣ 📜 script.js    # Логика органайзера
    ┗ 📜 styles.css   # Основные стили
